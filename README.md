# nvim-lua-config

1. [Install lazy package manager](https://github.com/folke/lazy.nvim)
2. [Install rg](https://github.com/BurntSushi/ripgrep#installation)
3. [Install fd](https://github.com/sharkdp/fd#installation)
4. [Install delve](https://github.com/go-delve/delve/tree/master/Documentation/installation)
5. [Setup nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter#quickstart)
6. [Install nerdfont](https://www.nerdfonts.com/font-downloads)
7. execute ```:Lazy```
